# Experimentos

A matriz é um plano, não um registro de execuções. Antes de rodar, criar para cada execução um manifesto versionado com ID, commit, snapshot/hash, definição de rótulo, população, folds e intervalos, hiperparâmetros, sementes, orçamento, ambiente, métricas e caminhos dos artefatos. Saídas locais ficam em `results/` e dados em `data/`; não registrar credenciais. Comparações com rotulagem alterada dependem de uma regra congelada e da definição de população comum.
